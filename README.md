# 🚀 Trace — Página de Presentación de Startup

> ✅ **Estado del proyecto:** En desarrollo | Versión actual: Diseño funcional con interactividad

---

### 📋 Descripción

Página web de presentación para una startup, desarrollada como práctica y consolidación de conocimientos en **HTML, CSS y JavaScript**, utilizando **Vite** como entorno de desarrollo. Incluye diseño moderno, secciones dinámicas y componentes interactivos que mejoran la experiencia del usuario.

---

### ✨ Funcionalidades Implementadas

#### 🎠 Sección Principal — Carrusel Automático
- Las imágenes del banner principal **cambian de forma automática** con transiciones suaves.
- Visualización continua y dinámica sin necesidad de intervención del usuario.

#### 📱 Sección de Características — Imagen Dinámica
- Al hacer clic en cada característica del listado, **se actualiza la imagen mostrada** según la selección.
- Interfaz interactiva que vincula cada elemento de texto con su correspondiente ilustración.

#### 🎨 Diseño y Estructura
- Diseño limpio con paleta de colores profesional (azul oscuro / azul claro / blanco).
- Secciones organizadas: Inicio, Características, Precios, Pie de página.
- Tarjetas de planes de precios resaltando el plan recomendado.
- Navegación superior con enlaces: Características, Precios, Inicio de Sesión, Descargar.

---

### 🛠️ Tecnologías Utilizadas

| Herramienta    | Uso                                                              |
| -------------- | ---------------------------------------------------------------- |
| **HTML5**      | Estructura semántica de todas las secciones                      |
| **CSS3**       | Estilos, diseño responsivo, animaciones y apariencia visual      |
| **JavaScript** | Lógica del carrusel automático y cambio de imágenes por clic     |
| **Vite**       | Entorno de desarrollo, servidor local y empaquetado del proyecto |

## 📦 Instalación y Ejecución

```bash

cd trace-startup

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo con Vite
